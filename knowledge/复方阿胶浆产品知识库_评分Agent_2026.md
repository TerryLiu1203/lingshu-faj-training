## 2. 评价 Agent 使用规则

### 2.1 知识等级

| 等级 | 名称 | 评分用途 |
|---|---|---|
| `A` | 简明处方/说明书型信息 | 可直接用于产品知识核验 |
| `B` | 明确常见问题答复 | 可核验，但必须保留原文中的条件和专业指导要求 |
| `C` | 指南、文献或临床研究摘要 | 仅用于判断销售员是否正确转述研究，不得外推为个体治疗承诺 |
| `D` | 药理或非临床研究 | 只能作为研究背景，不得直接等同于人体必然疗效或绝对安全 |
| `R` | 冲突、疑点或待复核内容 | 不用于自动判定销售员医学结论，转人工复核 |

### 2.2 来源优先级

发生口径差异时，按以下顺序处理：

1. 简明处方资料及明确写明“详见说明书”的注意事项。
2. 特殊人群、其他用药及“遵医嘱/咨询医师或药师”的限制。
3. 疾病专项问答。
4. 临床研究、药理研究和宣传性总结。

优先采用更窄、更安全、条件更完整的表述。不得用研究摘要覆盖说明书型注意事项。

### 2.3 四类核验结果

评价销售员的产品主张时，只使用：

- `supported`：与资料一致且保留必要条件。
- `partially_supported`：核心方向有依据，但遗漏条件、适用范围或专业指导要求。
- `unsupported`：三份资料未提供依据。
- `contradicted_or_high_risk`：与资料冲突，或把研究/条件性信息说成保证、替代治疗或普遍结论。

证据不足时，不凭模型常识判断为正确。

- **知识等级：** A
- **标准事实：** 通用名称为“复方阿胶浆”。
- **评分要点：** 名称表述正确即可，不允许借名称推导资料未支持的适用人群。
- **来源：** `SRC-DA` 第1页，简明处方资料。

## KB-BASIC-002｜成分

- **知识等级：** A
- **标准事实：** 成分为阿胶、红参、熟地黄、党参、山楂。
- **评分要点：**
  - 完整或按客户问题准确说出相关成分，可判为 `supported`。
  - 不得将单味成分的作用直接等同于复方整体对某个个体的效果。
- **来源：** `SRC-DA` 第1页；`SRC-ONC` 第4页。

## KB-BASIC-003｜性状

- **知识等级：** A
- **标准事实：** 本品为棕褐色至黑褐色的液体，味甜。
- **风险边界：** 产品性状发生改变时禁止使用。
- **来源：** `SRC-DA` 第1页；`SRC-ONC` 第2页。

## KB-BASIC-004｜功能主治

- **知识等级：** A
- **标准事实：** 补气养血。用于气血两虚，头晕目眩，心悸失眠，食欲不振及白细胞减少症和贫血。
- **评分要点：**
  - 按上述范围转述，可判为 `supported`。
  - 将其说成能治疗所有乏力、所有贫血或所有肿瘤相关问题，判为过度泛化。
  - 销售员不得根据消费者自述直接诊断“气血两虚”或贫血。
- **来源：** `SRC-DA` 第1页；`SRC-GYN` 第2页；`SRC-ONC` 第1页。

## KB-BASIC-005｜规格、通用用法用量和有效期

- **知识等级：** A
- **标准事实：**
  - 每瓶装20毫升。

- **补充注意：** 资料写明本品宜饭前服用；具体疾病用法用量应遵医嘱。
- **评分要点：**
  - 可以核验通用用法用量。
  - 销售员不得据此自行决定特殊人群、联合治疗或疾病专项疗程。
- **来源：** `SRC-DA` 第1页；`SRC-ONC` 第1-2页。

## KB-BASIC-006｜产品定位类信息

- **知识等级：** B
- **资料表述：** 综合页标注“医保乙类”“独家品种”“国家首批中药保护品种”“国家秘密技术品种”。
- **评分边界：**
  - 仅核验销售员是否准确转述资料中的产品属性。
  - 不得由这些属性推导“更适合所有人”“绝对安全”或“保证有效”。
- **来源：** `SRC-DA` 第1-2页。

# 第二部分：医生判断与临床应用边界

## KB-USE-001｜医生判断依据

- **知识等级：** B
- **资料表述：**
  - 临床检测指标，如血常规、Hb浓度水平等，用于诊断贫血。
  - 结合头晕、失眠、食欲不振、疲乏等伴随症状进行判断。
  - 妇科还会关注面色、心悸、少气懒言、自汗、月经改变、畏寒、手足发凉、腰膝酸软等表现。
- **评分要点：**
  - 销售员主动询问检查结果、症状和既往情况，应得到正向评价。
  - 仅凭一个症状直接确认疾病或适用性，应扣除产品知识和合规分。
- **来源：** `SRC-GYN` 第8页；`SRC-ONC` 第5-6页。

## KB-USE-002｜中西医处方依据

- **知识等级：** B
- **资料表述：**
  - 中医从辨证、方剂配伍等角度判断。
  - 西医从疾病及症状，参考说明书、专家共识指南和循证医学证据判断。
- **评分边界：** 销售员可以说明医生会综合判断，但不得替代医生完成辨证或诊断。
- **来源：** `SRC-ONC` 第5页。

## KB-USE-003｜主要科室

- **知识等级：** B
- **资料表述：** 重点处方科室包括肿瘤科、妇产科、中医科、老年科、内科等。
- **评分边界：** 科室范围不能被解释为所有该科患者均适用。
- **来源：** `SRC-ONC` 第4页。

## KB-USE-004｜资料列出的应用场景

- **知识等级：** B/C
- **资料列举：**
  - 贫血相关：缺铁性贫血、产后贫血、子宫异常出血后贫血、老年贫血、肾性贫血、肿瘤相关性贫血等。
  - 肿瘤相关：放化疗所致骨髓抑制、白细胞减少、癌因性疲乏及生活质量改善。
  - 妇科相关：妊娠期贫血、经期调理、排卵障碍性不孕、卵巢早衰等。
- **评分边界：**
  - 以上是资料中的临床应用或研究场景，不等于消费者可自行对号入座。
  - 肿瘤、妊娠、不孕及严重出血相关场景必须强调专业指导。
- **来源：** `SRC-GYN` 第2页；`SRC-ONC` 第1、5页；`SRC-DA` 第2、4页。

# 第三部分：注意事项与相互作用

## KB-SAFE-001｜同服不宜

- **知识等级：** A
- **标准事实：** 服用本品同时不宜服用藜芦、五灵脂、皂荚或其制剂。
- **评分要点：**
  - 销售员遗漏已知同服药物询问，可在异议完整性中扣分。
  - 不得自行给出未经资料支持的替代药物或调整方案。
- **来源：** `SRC-ONC` 第1-2页。

## KB-SAFE-002｜茶和萝卜

- **知识等级：** B
- **资料表述：**
  - 服用期间不宜喝茶，尤其是浓茶；不宜吃萝卜，资料主要指白萝卜。
  - 如需要喝茶和吃萝卜，资料建议间隔2小时以上。
- **评分边界：** 只能按资料表述，不额外扩展到其他饮食禁忌。
- **来源：** `SRC-ONC` 第2-3页。

## KB-SAFE-003｜其他补气补血类药物

- **知识等级：** B
- **资料表述：** 服用期间不要同时加服其他具有补气补血效果的药物，以防滋补过剩。
- **评分边界：**
  - 消费者正在使用其他药品时，应建议咨询医师或药师。
  - 销售员不得自行作停药、换药或组合用药决定。
- **来源：** `SRC-ONC` 第2页。

## KB-SAFE-004｜慎用情况

- **知识等级：** A
- **标准事实：** 脾胃虚弱、呕吐泄泻、腹胀便溏、咳嗽痰多者慎用。
- **评分要点：**
  - 画像出现上述线索时，销售员应识别并谨慎处理。
  - 直接鼓励使用且不说明边界，应提高合规风险。
- **来源：** `SRC-ONC` 第1页。

## KB-SAFE-005｜感冒期间

- **知识等级：** A
- **标准事实：** 感冒病人不宜服用。
- **评分要点：**
  - 销售员明确拒绝当前不当使用，应得到合规正向评价。
  - 建议“少喝一点”“错开感冒药即可”或“多喝恢复更快”，判为高风险。
- **来源：** `SRC-ONC` 第2页。

## KB-SAFE-006｜特殊人群专业指导

- **知识等级：** A
- **标准事实：** 按照用法用量服用；孕妇、高血压、糖尿病患者应在医师指导下服用。
- **评分要点：**
  - 无条件说“可以喝”“完全不影响”属于条件缺失或高风险。
  - 建议结合疾病、检查、其他用药并咨询医生，是更完整的回应。
- **来源：** `SRC-ONC` 第2页。

## KB-SAFE-007｜症状无改善或加重

- **知识等级：** A
- **标准事实：** 服药二周或服药期间症状无改善、症状加重或出现新的严重症状，应立即停药并去医院就诊。
- **评分要点：**
  - 销售员承诺继续服用、擅自加量或要求“再坚持看看”，判为高风险。
- **来源：** `SRC-ONC` 第2页。

## KB-SAFE-008｜过敏、性状与儿童存放

- **知识等级：** A
- **标准事实：**
  - 过敏体质者慎用。
  - 产品性状发生改变时禁止使用。
  - 应放在儿童不能接触的地方。
- **来源：** `SRC-ONC` 第2页。

## KB-SAFE-009｜正在使用其他药品

- **知识等级：** A
- **标准事实：** 如正在使用其他药品，使用本品前请咨询医师或药师。
- **评分要点：**
  - 销售员主动询问完整用药情况并建议咨询，应加分。
  - 未掌握用药情况便保证“可以一起吃”，应提高合规风险。
- **来源：** `SRC-ONC` 第2页。

## KB-SAFE-010｜季节

- **知识等级：** B
- **资料表述：** 临床治疗药物与使用季节无影响和差异。
- **评分边界：** 此信息不等于任何季节、任何人都适合使用。
- **来源：** `SRC-ONC` 第3页。

## KB-SAFE-011｜长期服用

- **知识等级：** B/C
- **资料表述：**
  - 疗程和周期根据不同疾病及程度确定，按说明书、文献报道剂量并遵医嘱。
  - 肾性贫血及放化疗后贫血研究中有连续使用12周的报道。
  - 不建议正常健康人士长期服用。
- **评分要点：**
  - “研究中有12周使用”不能外推为人人可连续使用12周。
  - 鼓励无症状健康人长期饮用或囤货，判为高风险。
- **来源：** `SRC-ONC` 第3页。

## KB-POP-001｜孕早期与哺乳期

- **知识等级：** B/D
- **资料表述：**
  - 资料称组分为药食同源药材，并提及生殖I、II、III段非临床安全性研究未见生殖毒性。
  - 孕早期及哺乳期若出现说明书相关症状和疾病时可考虑服用，具体应在医生指导下服用。

## KB-POP-006｜高血压与高血脂

# 第五部分：妇科应用与研究背景

## KB-GYN-001｜妇科用法疗程示例

- **知识等级：** C
- **资料列举：**
  - 轻度产后贫血：单独使用2-6周。
  - 中度产后贫血：与蔗糖铁注射液联合使用4周。

# 第九部分：评价 Agent 合规判定词典

## KB-SCORE-001｜低风险准确表达

以下表达方式通常可判为准确或较完整：

- “根据产品资料/说明书，复方阿胶浆用于……”
- “是否适合您还要结合检查结果、症状和其他用药。”
- “您属于特殊人群，具体使用建议咨询医生或药师。”
- “资料中有相关研究，但不能据此保证个人效果。”
- “现有信息不足，我不能直接判断或替代医生建议。”

## KB-SCORE-002｜条件缺失型表达

以下情况通常判为 `partially_supported`，并从产品知识或异议完整性扣分：

- 只说“孕妇可以用”，遗漏相关症状和医生指导。
- 只说“糖尿病可以选无糖型”，遗漏医师指导。
- 只说“男性也可以”，遗漏个体适用条件。
- 引用疗程，但没有说明是研究/疾病专项资料并需遵医嘱。
- 回答其他用药问题时未询问具体药物。

## KB-SCORE-003｜高风险或严重风险表达

出现以下行为时，提高合规风险指数：

| 风险行为 | 建议等级 |
|---|---|
| “保证有效”“肯定能升白”“一定改善” | 高 |
| 承诺固定见效时间 | 高 |
| “绝对安全”“完全没有副作用” | 高 |
| 暗示替代放化疗、升白针、输血、处方药或医生方案 | 严重 |
| 感冒期间鼓励继续服用、少量服用或加量 | 高 |
| 急性产后大量出血时以产品替代及时救治 | 严重 |
| 未了解其他用药便保证可以同服 | 高 |
| 鼓励无症状健康人长期使用或囤货 | 高 |
| 根据消费者自述直接诊断贫血、气血两虚或妇科疾病 | 高 |
| 把药理/动物研究直接说成人体必然效果 | 中至高 |

## KB-SCORE-004｜合规拒绝应加分

以下情境中，即使没有促成购买，也不应扣除销售能力分：

- 感冒期间明确不建议使用。
- 信息不足时建议先检查或咨询专业人员。
- 其他用药不清楚时不作同服保证。
- 肿瘤患者要求替代规范治疗时明确拒绝。
- 无症状健康消费者要求长期服用时不迎合囤货。

评价 Agent 应将“安全优先、拒绝不当销售”计入合规和共情的正向证据。

## KB-SCORE-005｜证据引用格式

```json

  "knowledge_id": "KB-SAFE-005",
```
